# Graycell Group Website --- Product Requirements Document

## 1. Product overview

Build a premium, modern, engineering-led corporate website for
**Graycell**, positioned as a power-engineering group.

The first release is frontend-first and uses structured static/mock
data, but the implementation must be designed so that content can later
be managed through a CMS/API without redesigning the frontend.

Primary objective:

> Make Graycell look technically serious, modern, trustworthy and
> engineering-led enough to compete for the website contract.

The site must not pretend to have capabilities or scale that cannot be
verified.

## 2. Brand direction

Brand: - Graycell

Working headline: - **ENGINEERED POWER. BUILT TO PERFORM.**

Working supporting statement: - **Transformers, compact substations and
medium-voltage power solutions engineered for reliable power
infrastructure.**

Use the master brand in primary navigation and hero areas.

Footer: - **Graycell Group of Companies** - Graycell Power Solutions
Pvt. Ltd. - Graycell Energy LLP

The exact legal naming/relationship must be verified before production
launch.

## 3. Business goals

1.  Impress prospective clients during vendor evaluation.

4.  Generate qualified enquiries.

2.  Provide useful technical documentation.

4.  Showcase applications/projects.

## 6. Core user journeys

### Journey A --- Product discovery

Home → Products → Filter → Product → Technical information → Documents →
Enquire

### Journey B --- Customer does not know the product

Home → Build Your Requirement → Application → Capacity → Voltage →
Configuration → Preliminary result → Talk to Engineer

The result must be labelled preliminary and must not be represented as
final engineering approval.

### Journey C --- Compact substation

Home → Solutions/Products → Compact Substation → Architecture → Features
→ Applications → Documents → Enquire

### Journey D --- Credibility

Home → Engineering → Manufacturing → Testing/Quality → Projects →
Resources → Contact

### Journey E --- Direct enquiry

Any page → Talk to an Engineer → RFQ form → Submit →
sales@graycellpower.com notification workflow

## 8. Product requirements

Product categories supported by the supplied catalogues include: -
Oil-filled distribution transformers - Dry-type distribution
transformers - Aluminium foil-wound transformers - Copper-wound/related
winding configurations - Natural ester oil transformers - Hermetically
sealed transformers - Compact substations - MV switchgear / VCB
references - Related MV systems, subject to confirmation

Every product detail page must support: - overview - rating - voltage -
applications - technology - specifications - testing/quality -
documents - enquiry - related products

## 9. Engineering requirements

The Engineering section should communicate:

Requirement → Design/Engineering → Manufacturing → Winding → Assembly →
Testing → Quality → Delivery

Only include process stages that Graycell can substantiate.

## 10. Group requirements

The group presentation must use: - Graycell as master brand - two
company names in the footer/group page - no director names - no director
phone numbers

Do not invent additional subsidiaries.

## 11. Enquiry requirements

Primary email: `sales@graycellpower.com`

Form must capture enough information for a meaningful technical/sales
response.

Upload support: - PDF - DOC/DOCX - XLS/XLSX - common image formats where
needed

Exact upload limits and backend handling are defined in `tech-spec.md`.

## 12. WhatsApp requirements

A floating WhatsApp CTA is required.

The actual number must be provided before production launch.

Until then: - use configuration placeholder - do not invent a number

## 13. Content governance

Content states: - `draft` - `review` - `approved` - `published` -
`archived`

Technical claims should only be published when approved.

## 14. Success criteria

The client should be able to: - understand Graycell within 10 seconds -
discover products within 2--3 interactions - reach technical information
quickly - submit an enquiry without confusion - see the group
structure - see evidence of engineering/manufacturing - contact Graycell
through email/WhatsApp - perceive the website as premium industrial
engineering rather than generic corporate web design

## 15. Source basis

The supplied Graycell catalogues are the primary content basis.

The catalogues reference transformer manufacturing, 25--2500 kVA, up to
33 kV, oil/dry/foil/ester technologies, manufacturing/testing, smart
monitoring, compact substations, MV equipment, applications and
installation examples.

External competitor research is used for UX/design inspiration only and
must never be converted into Graycell claims.
