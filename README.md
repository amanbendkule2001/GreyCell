# Graycell Engineered Power Website

Frontend-first Next.js implementation of the Graycell corporate website.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Visual direction

Light, minimal industrial-corporate UI based on the supplied reference screenshot: white navigation/content, deep blue typography, electric-blue actions, thin technical dividers, restrained cards, and a dark footer only.

## Images

Product and application imagery under `public/images` is sourced from the supplied Graycell product catalogue. AI-generated imagery is not used as documentary product evidence.

## Content governance

Technical values marked for confirmation in the source data remain labelled as such and should be reviewed before production publication.
